# Introduction à l’IA pour l’agriculture

Site de formation en français consacré à Python, l’analyse de données,
le machine learning et l’analyse géospatiale appliqués à l’agriculture.

## Dépôt GitHub

https://github.com/Miorat/ai-agriculture-course

## Site GitHub Pages

https://Miorat.github.io/ai-agriculture-course/

## Prévisualiser le site

```bash
quarto preview
```

## Structure principale

- `index.qmd` — page d’accueil
- `programme.qmd` — programme et objectifs pédagogiques
- `ressources.qmd` — ressources pédagogiques
- `modules/` — chapitres du cours
- `images/` — logos et éléments visuels
- `styles.css` — design du site
- `_quarto.yml` — configuration Quarto

## Publication

Lorsque le dépôt sera prêt à être rendu public :

```bash
quarto publish gh-pages
```
