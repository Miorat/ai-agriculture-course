Variables et types de données

Objectifs

À la fin de cette partie, vous serez capables de :

  • créer et utiliser une variable en Python ;
  • reconnaître les principaux types de données ;
  • afficher et vérifier la valeur d’une variable ;
  • utiliser des variables dans des calculs simples ;
  • manipuler des listes ;
  • organiser des informations à l’aide de dictionnaires ;
  • représenter des données agricoles simples avec Python.

Les variables

Une variable permet de stocker une information dans un programme.

Elle possède :

  • un nom ;
  • une valeur ;
  • un type de données.

Par exemple :

surface = 8

Ici :

  • surface est le nom de la variable ;
  • 8 est sa valeur ;
  • la valeur est un nombre entier.

Pour afficher la valeur :

print(surface)

Résultat :

8

Les principaux types de données

Python permet de manipuler différents types d’informations.

Type Python Exemple
Texte str "Vakinankaratra"
Nombre entier int 8
Nombre décimal float 8.0
Vrai / Faux bool True
Liste list [24, 26, 29]
Dictionnaire dict {"culture": "riz"}

Chaîne de caractères : str

Une chaîne de caractères permet de stocker du texte.

nom_region = "Vakinankaratra"

Pour afficher la valeur :

print(nom_region)

Résultat :

Vakinankaratra

On peut vérifier le type avec type() :

type(nom_region)

Résultat :

str

Nombre entier - int

Un entier est un nombre sans partie décimale.

nombre_parcelles = 5
surface = 8
type(surface)

Résultat :

int

Nombre décimal - float

Un nombre décimal possède une partie décimale.

surface_decimale = 8.0
type(surface_decimale)

Résultat :

float

Les valeurs décimales sont très fréquentes dans les données agricoles :

ph_sol = 6.8
precipitations = 12.5
rendement = 3.2

Valeur booléenne - bool

Une variable booléenne possède seulement deux valeurs possibles :

True
False

Par exemple :

irrigation_active = True
maladie_detectee = False

Ces variables peuvent servir à représenter l’état d’une parcelle ou d’un système.

Déclarer des variables agricoles

On peut utiliser plusieurs variables pour décrire une situation agricole.

nom_region = "Itasy"
ph_sol = 6.8
precipitations = 12.5
rendement = 3.2

Chaque variable représente une information différente.

Afficher des informations avec print()

La fonction print() permet d’afficher une information.

surface = 17
print(surface)

On peut également combiner du texte et des variables :

nom_region = "Vakinankaratra"
surface = 17

print("Région étudiée :", nom_region)
print("Surface :", surface)

Déclarer plusieurs variables en une ligne

Python permet de créer plusieurs variables simultanément.

region, annee, production = "Alaotra", 2025, 25

Puis :

print("Région :", region)
print("Année :", annee)
print("Production totale :", production)

Utiliser les variables dans un calcul

Les variables peuvent être utilisées dans des opérations mathématiques.

Exemple : calcul du rendement

Supposons :

production = 1000
surface = 500

Le rendement est calculé par :

[ Rendement = ]

En Python :

rendement = production / surface
print(rendement)

Résultat :

2.0

Exemple : production de plusieurs parcelles

production_parcelle_a = 650
production_parcelle_b = 850
production_parcelle_c = 1050

production_totale = (
    production_parcelle_a
    + production_parcelle_b
    + production_parcelle_c
)

print(production_totale)

Résultat :

2550

On peut produire un affichage plus explicite :

nom_region = "Vakinankaratra"

print(
    "Production totale dans la région",
    nom_region,
    ":",
    production_totale,
    "tonnes"
)

Les commentaires

Les commentaires permettent d’expliquer le code.

Ils commencent par le symbole #.

# Type de culture
type_culture = "Vivrière"

# Surface de l'exploitation
surface_exploitation = 10

Un commentaire peut également être ajouté à la fin d’une ligne :

surface_exploitation = 10  # unité : are
NotePourquoi commenter le code ?

Les commentaires permettent de rendre un programme plus facile à comprendre, à vérifier et à réutiliser.

Les listes

Une liste permet de regrouper plusieurs valeurs dans une même variable.

temperatures = [24, 26, 29, 31]

Chaque élément possède une position appelée indice.

En Python, le premier élément correspond à l’indice 0.

Valeur       24   26   29   31
Indice        0    1    2    3

Pour accéder au premier élément :

print(temperatures[0])

Pour accéder au quatrième élément :

print(temperatures[3])

Exemple : liste de cultures

cultures = ["Maïs", "Riz", "Haricot"]

print(cultures[0])
print(cultures[1])

Calculer un rendement moyen

rendements = [3.2, 2.8, 4.1, 3.6, 2.9]

rendement_moyen = sum(rendements) / len(rendements)

print(rendement_moyen)

Le résultat est environ :

3.32

Les dictionnaires

Un dictionnaire permet d’organiser plusieurs informations sous forme de paires clé → valeur.

Il est particulièrement utile pour décrire :

  • une parcelle ;
  • une exploitation ;
  • une culture ;
  • une observation météorologique ;
  • une observation de terrain.

Exemple : représenter une parcelle

parcelle = {
    "nom": "Ankadikely",
    "culture": "Maïs",
    "surface": 5,
    "rendement": 3.4
}

Pour accéder à une information :

print(parcelle["culture"])
print(parcelle["surface"])

Exemple avec davantage d’informations

parcelle = {
    "culture": "riz",
    "surface_ha": 2.5,
    "rendement_t_ha": 3.2,
    "region": "Alaotra-Mangoro",
    "temperature": 28,
    "ph": 3.5
}
print(parcelle["culture"])
print(parcelle["rendement_t_ha"])

Exemple : observation climatique

observation_climatique = {
    "date": "2026-08-07",
    "temperature": 28.5,
    "precipitations": 12,
    "humidite": 75
}
print(observation_climatique["temperature"])
print(observation_climatique["precipitations"])

Combiner listes et dictionnaires

observations_climatiques = [
    {
        "date": "2026-08-01",
        "temperature": 27.5,
        "precipitations": 5,
        "humidite": 70
    },
    {
        "date": "2026-08-02",
        "temperature": 28.0,
        "precipitations": 0,
        "humidite": 68
    },
    {
        "date": "2026-08-03",
        "temperature": 29.2,
        "precipitations": 2,
        "humidite": 65
    }
]

Pour afficher la première observation :

print(observations_climatiques[0])

Pour afficher sa température :

print(observations_climatiques[0]["temperature"])
