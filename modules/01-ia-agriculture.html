IA dans l’agriculture

Qu’est-ce que l’intelligence artificielle ?

L’intelligence artificielle (IA) regroupe un ensemble de méthodes informatiques permettant à une machine de réaliser certaines tâches d’analyse, de prédiction ou de classification à partir de données.

Dans ce cours, nous nous intéressons principalement aux approches basées sur les données, en particulier au Machine Learning.

Par exemple, un système d’IA peut être utilisé pour :

  • reconnaître des tendances dans des données agricoles ;
  • classer des observations ;
  • détecter des anomalies ;
  • prédire un rendement ou un risque ;
  • produire des recommandations à partir de données disponibles.

L’IA ne remplace pas l’expertise agronomique.

Elle fournit plutôt des outils permettant d’exploiter des données afin de mieux comprendre une situation et d’appuyer la prise de décision.

NoteIA, Machine Learning et données

Intelligence artificielle
Terme général regroupant différentes méthodes permettant à une machine de réaliser des tâches d’analyse, de prédiction ou de décision.

Machine Learning
Sous-domaine de l’IA dans lequel les modèles apprennent des relations à partir de données.

Données
Informations utilisées pour entraîner, tester et appliquer ces modèles.

Le secteur agricole doit aujourd’hui répondre à plusieurs défis :

  • améliorer la production et les rendements ;
  • s’adapter aux changements climatiques ;
  • gérer durablement les ressources naturelles ;
  • suivre l’état des cultures et des exploitations ;
  • anticiper les risques agricoles ;
  • améliorer la prise de décision.

Dans ce contexte, les données occupent une place de plus en plus importante.

Elles peuvent provenir de différentes sources :

  • observations de terrain ;
  • données météorologiques et climatiques ;
  • données sur les sols ;
  • données historiques de production ;
  • fichiers Excel ;
  • coordonnées GPS ;
  • images satellites ;
  • images acquises par drone ;
  • observations sur les ravageurs et les maladies.

L’objectif n’est pas seulement de collecter ces données, mais surtout de les transformer en informations utiles pour comprendre une situation et appuyer une décision.

NoteIdée clé

Une donnée brute n’est pas encore une décision.

Elle doit être collectée, préparée, analysée puis interprétée avant de pouvoir être utilisée dans un contexte agricole.

Comment l’IA intervient en agriculture

L’intelligence artificielle intervient au sein d’une chaîne plus large de traitement des données.

ImportantDe la donnée à la décision

1. Collecte des données
Données Excel, météo, GPS, observations de terrain, images satellites, drones, sols et pratiques culturales.

2. Préparation et exploration
Nettoyage, visualisation et combinaison des données, notamment avec Python.

3. Analyses et modélisation
Analyse statistique, Machine Learning et analyse géospatiale.

4. Décision et interprétation
Prévisions, recommandations, alertes précoces, cartes et aide à la décision.

Collecte et préparation des données

Avant de construire un modèle, les données doivent généralement être préparées.

Avec Python, il est possible de :

  • nettoyer les données ;
  • identifier les valeurs manquantes ;
  • explorer les variables ;
  • produire des graphiques ;
  • fusionner plusieurs sources de données ;
  • préparer un jeu de données pour la modélisation.

Analyse statistique

L’analyse statistique permet notamment de :

  • comprendre les tendances ;
  • identifier les facteurs associés à un phénomène ;
  • comparer des groupes ;
  • tester des hypothèses.

Machine Learning

Le Machine Learning est utilisé lorsque l’on souhaite construire un modèle capable d’apprendre à partir de données historiques.

Le modèle peut ensuite être utilisé pour :

  • faire une prédiction ;
  • classer une observation ;
  • détecter une situation particulière ;
  • produire une probabilité de risque.

SIG

Les systèmes d’information géographique permettent d’ajouter la dimension spatiale à l’analyse.

Ils permettent notamment de :

  • produire des cartes ;
  • identifier des zones prioritaires ;
  • croiser plusieurs couches d’information ;
  • analyser la variabilité spatiale.

AstuceOutil utilisé : modèle de Machine Learning

On peut construire un modèle de régression à partir de données historiques.

Le modèle apprend la relation entre les caractéristiques de la parcelle et le rendement observé.

Il peut ensuite être utilisé pour estimer le rendement attendu d’une nouvelle parcelle.

Exemples de modèles :

  • régression linéaire ;
  • Random Forest ;
  • Gradient Boosting.

Points à retenir

AstuceÀ retenir
  • L’IA utilise des données pour apprendre des relations et produire des prédictions ou des classifications.
  • Le Machine Learning est une des principales approches de l’IA utilisées dans ce cours.
  • Avant de construire un modèle, les données doivent être nettoyées, explorées et préparées.
  • Les modèles peuvent être utilisés pour estimer des rendements, identifier des risques ou produire des recommandations.
  • Les SIG et la télédétection permettent d’ajouter la dimension spatiale à l’analyse.
  • L’objectif final est d’appuyer une décision agricole, et non simplement de produire un modèle.
