Pandas et exploration des données

Objectifs

À la fin de cette partie, vous serez capables de :

  • importer un fichier Excel ;
  • afficher les premières lignes d’un DataFrame ;
  • inspecter les types de variables ;
  • identifier les valeurs manquantes et les doublons ;
  • sélectionner, filtrer et trier des données ;
  • utiliser groupby() pour produire des statistiques par groupe.

Importer Pandas

import pandas as pd

Charger les données FAOSTAT

df = pd.read_excel("../data/FAOSTAT_data_MDG.xlsx")
df.head()

Explorer le DataFrame

df.shape
df.columns
df.info()

Vérifier la qualité des données

df.isna().sum()
df.duplicated().sum()

Examiner les valeurs disponibles

df["Item"].unique()
df["Element"].unique()
df["Year"].min()
df["Year"].max()

Filtrer les rendements

table_rendement = df[df["Element"] == "Yield"]
table_rendement.head()

Filtrer une culture

mais = table_rendement[
    table_rendement["Item"] == "Maize (corn)"
]

mais.head()

Trier les données

table_rendement.sort_values(
    "Value",
    ascending=False
).head()

Renommer les colonnes

df = df.rename(columns={
    "Area": "Pays",
    "Item": "Culture",
    "Element": "Indicateur",
    "Year": "Annee",
    "Unit": "Unite",
    "Value": "Valeur"
})

Agrégation avec groupby()

table_rendement = df[df["Indicateur"] == "Yield"]

table_rendement.groupby(
    "Culture"
)["Valeur"].describe()

AstuceÀ retenir

Avant de produire un graphique ou un test statistique, il faut d’abord comprendre la structure du jeu de données, vérifier sa qualité et identifier clairement les variables à analyser.
